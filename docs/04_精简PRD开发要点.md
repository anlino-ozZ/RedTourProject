# 04 精简 PRD 开发要点

> 本文件为开发用精简要点，完整业务 PRD / 变更记录 / 风险表存放于外部腾讯文档。

## 一、产品定位

面向红色景区的**可离线、AI 驱动**智能导览与互动系统。核心差异化：不需网络（乡村可用）、支持姿态识别互动、AI 回答基于本地史料（不瞎编）、成本低（一套约 2000 元）。

## 二、用户角色与权限

| 角色 | 简称 | 使用端 | 主要权限 |
| --- | --- | --- | --- |
| 超级管理员 | 超管 | 管理端 Web | 全系统管理、用户管理、全局配置、模型切换 |
| 普通管理员 | 普管 | 管理端 Web | 分管指定景区的内容与数据（景区/知识库/问答/剧本/文物） |
| 游客 | 游客 | 游客端 Web | 智能导览、问答、互动、个人中心、特产 |
| 触摸屏端用户 | 触摸屏 | 触摸屏专用 | 固定位置快速问答与姿态互动，无登录 |

## 三、功能模块速览

### 游客端（6 模块）
首页（推荐/热门路线）、智能导览（路线推荐/景点导航/讲解）、智能问答（语音/文字，AI 基于本地史料）、沉浸式互动（红色剧本杀、姿态识别）、个人中心（游览记录/成就徽章/收藏）、特色产品中心（特产推荐/购买）。

### 触摸屏端（4 模块）
简洁首页、语言提问（语音输入）、姿态互动（敬礼/推磨触发讲解）、快捷信息。与游客端区别：无复杂导航、无登录、超大按钮。

### 管理端
用户管理、地区/景区/景点/路线/打卡点管理、知识库管理（录入资料/上传文档/编译 Wiki）、问答管理（问题答案/推荐问题）、故事/剧本管理（角色/成就/剧情）、文物管理（品类关联 Wiki）、用户分析、设备管理（状态查看）。

## 四、核心指标

| 维度 | 目标 |
| --- | --- |
| 技术指标 | 离线运行 100% 可用，问答响应 ≤ 3 秒 |
| 游客体验 | 平均游览时长提升 30% 以上 |
| 知识传播 | 游客历史知识测试正确率 ≥ 85% |
| 乡村经济 | 特产推荐点击率 ≥ 20%，转化率 ≥ 5% |
| 大赛目标 | 冲击国赛金奖 |

## 五、关键技术要点

- **LLM Wiki**：史料编译为结构化 Markdown 百科，摄入时合成、`[[wiki-links]]` 互联、知识复利；纯文件系统，适配树莓派离线。
- **机架工程 Harness**：LocalContextMiddleware 注入环境地图（零回合定向）、推理三明治、验证门核对 Wiki 引用，确保史实严谨。
- **YOLOv8-pose + Hailo8L**：30+ FPS 姿态识别，敬礼/推磨/挥手触发讲解；文物感知主动介绍。
- **Ollama 本地推理**：问答不依赖外网，响应 ≤ 3 秒。

## 六、开发优先级

| 优先级 | 模块 |
| --- | --- |
| P0（阻塞） | 后端鉴权与基础接口、AI 问答（LLM Wiki + Ollama）、游客端导览与问答、树莓派离线部署 |
| P1（重要） | 管理端景区/知识库管理、YOLO 姿态互动、触摸屏端、特产中心 |
| P2（增强） | 红色剧本杀、成就系统、用户分析、数据看板 |

## 七、数据实体（核心）

用户、景区、景点、导览路线、打卡点、Wiki 条目、问答记录、特产/文创、文物、剧本/角色/成就、设备状态。本地存储（游客游览记录/收藏）与云端存储（业务持久化）分层。
