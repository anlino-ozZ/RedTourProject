# 05 全局接口精简文档

> 前后端 AI 统一接口精简文档。响应结构、类型定义见 `public-common/api-types`。

## 一、通用约定

- 业务后端基址：`http://<host>:8000/api/v1`（前端 `VITE_API_BASE_URL`）。
- AI 引擎基址：`http://<host>:8001/engine`。
- 统一响应结构 `ApiResponse<T>`：

```json
{ "code": 0, "message": "ok", "data": {} }
```

- 鉴权：除登录/健康检查外，请求头携带 `Authorization: Bearer <JWT>`。
- 分页响应 `PageResult<T>`：`{ list, total, page, pageSize }`。
- 错误码：`0` 成功；`401` 未授权；`403` 无权限；`404` 资源不存在；`500` 服务异常。

## 二、业务后端接口（server-business :8000）

| 模块 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 鉴权 | POST | `/auth/login` | 登录，返回 token 与 UserInfo |
| 鉴权 | GET | `/auth/me` | 获取当前用户信息 |
| 景点 | GET | `/spots` | 景点列表（分页/关键词） |
| 景点 | GET | `/spots/{id}` | 景点详情（含 Wiki 引用） |
| 导览 | GET | `/routes` | 导览路线列表 |
| 导览 | GET | `/routes/{id}` | 路线详情（含景点序列） |
| 问答 | POST | `/ask` | 智能问答（透传 AI 引擎，返回 AskResult） |
| 特产 | GET | `/products` | 特产推荐列表 |
| 成就 | GET | `/achievements` | 当前游客成就 |
| 设备 | GET | `/devices/status` | 设备状态（在线/温度/内存） |
| 管理 | POST/PUT/DELETE | `/admin/spots`、`/admin/routes`、`/admin/wiki` 等 | 管理端 CRUD（需管理员权限） |

### 问答请求示例

```http
POST /api/v1/ask
Authorization: Bearer <token>
Content-Type: application/json

{ "question": "长征路上有哪些关键决策？", "scenicAreaId": 1, "useVoice": true }
```

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "question": "长征路上有哪些关键决策？",
    "answer": "遵义会议确立了……",
    "sources": ["wiki/遵义会议", "wiki/长征"],
    "durationMs": 2100
  }
}
```

## 三、AI 引擎接口（ai-engine :8001）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/engine/health` | 引擎健康检查（Ollama/Hailo/Wiki 状态） |
| POST | `/engine/ask` | 本地问答（经机架 Harness：上下文注入→推理三明治→验证门） |
| POST | `/engine/pose` | 姿态识别（上传帧/帧标识，返回 PoseResult） |

### 姿态识别响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "action": "salute",
    "confidence": 0.92,
    "keypoints": [[120, 80], ...],
    "timestamp": 1730000000000
  }
}
```

## 四、硬件事件（预留）

- 触摸屏/树莓派姿态事件可通过 WebSocket（`ws://<host>:8001/engine/ws/pose`）实时推送，供前端大屏联动。
- 设备心跳上报业务后端 `/devices/heartbeat`。

## 五、类型定义位置

所有请求/响应 TS 类型统一定义在 `public-common/api-types/index.ts`，三端与后端共用，修改接口须同步更新类型与本文件。
