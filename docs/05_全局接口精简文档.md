# 05 全局接口文档

> 前后端 AI 统一接口文档。响应结构、类型定义见 `public-common/api-types/index.ts`。
> 修改接口须同步更新类型定义与本文件。

## 一、通用约定

### 1.1 基址

| 服务 | 基址 | 说明 |
| --- | --- | --- |
| 业务后端 | `http://<host>:8000/api/v1` | 前端 `VITE_API_BASE_URL`；管理端接口前缀为 `${基址}/admin` |
| AI 引擎 | `http://<host>:8001/engine` | 仅业务后端 `AiEngineClient` 内部调用，**禁止前端直连** |

### 1.2 鉴权

- 除登录/注册、健康检查、触摸屏公开接口外，请求头须携带 `Authorization: Bearer <JWT>`
- JWT 有效期 2 小时，过期后返回 `401`，前端调用 `/auth/login` 重新登录
- 触摸屏端不登录，通过设备绑定景区 ID 访问公开接口

### 1.3 统一响应结构

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 1.4 错误码

| code | 含义 | 触发场景 |
| --- | --- | --- |
| 0 | 成功 | 正常请求 |
| 400 | 参数错误 | 请求参数校验失败 |
| 401 | 未授权 | token 缺失/过期 |
| 403 | 无权限 | 角色权限不足或跨景区访问 |
| 404 | 资源不存在 | 路径或 ID 无效 |
| 409 | 冲突 | 唯一约束冲突（如用户名重复） |
| 500 | 服务异常 | 后端内部错误 |

错误响应示例：

```json
{
  "code": 400,
  "message": "用户名长度需 3-20 字符",
  "data": null
}
```

### 1.5 分页约定

分页查询参数（Query）：

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| page | number | 1 | 页码，从 1 开始 |
| pageSize | number | 10 | 每页条数，最大 50 |
| keyword | string | - | 模糊搜索关键词 |

分页响应结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

## 二、鉴权模块

### POST /auth/login

登录获取 JWT token。

鉴权：无

请求体：

```json
{
  "username": "admin",
  "password": "123456"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名，3-20 字符 |
| password | string | 是 | 密码，6-32 字符 |

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "username": "admin",
    "nickname": "管理员",
    "role": "super_admin",
    "avatar": "/uploads/avatar/1.jpg",
    "scenicAreaId": null,
    "token": "eyJhbGciOiJIUzI1NiJ9..."
  }
}
```

错误情况：

| code | message | 场景 |
| --- | --- | --- |
| 401 | 用户名或密码错误 | 凭证不匹配 |
| 403 | 账号已禁用 | status=0 |

### GET /auth/me

获取当前登录用户信息。

鉴权：需要

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "username": "admin",
    "nickname": "管理员",
    "role": "super_admin",
    "avatar": "/uploads/avatar/1.jpg",
    "scenicAreaId": null
  }
}
```

### POST /auth/logout

登出，前端清除本地 token。后端可将 token 加入 Redis 黑名单。

鉴权：需要

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

### POST /auth/register

游客自助注册（仅注册 role=tourist；管理员账号由超管后台创建）。注册成功后直接返回 token，免二次登录。

鉴权：无

请求体：

```json
{
  "username": "tourist01",
  "password": "123456",
  "nickname": "游客小王"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名，3-20 字符，字母数字下划线，唯一 |
| password | string | 是 | 密码，6-32 字符 |
| nickname | string | 否 | 昵称，1-20 字符（不填默认用用户名） |

成功响应：与 /auth/login 一致（UserInfo + token）。

错误情况：

| code | message | 场景 |
| --- | --- | --- |
| 409 | 用户名已被占用 | 用户名重复 |

## 七、姿态识别模块

### POST /pose/recognize

姿态识别（上传图像帧进行单次识别）。

鉴权：无

请求体：

```json
{
  "frame": "base64编码的图像数据",
  "scenicAreaId": 1
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| frame | string | 是 | Base64 编码的图像帧 |
| scenicAreaId | number | 否 | 景区 ID，用于匹配触发内容 |

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "action": "salute",
    "confidence": 0.92,
    "keypoints": [[120, 80], [135, 85], [150, 90]],
    "triggerContent": {
      "title": "军礼的由来",
      "audioUrl": "/audio/pose/salute.mp3",
      "wikiRef": "wiki/军礼"
    },
    "timestamp": 1730000000000
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| action | string | salute / mill / wave / unknown |
| confidence | number | 置信度 0-1 |
| keypoints | number[][] | 关节点坐标 |
| triggerContent | object | 触发的讲解内容（action=unknown 时为 null） |
| timestamp | number | 识别时间戳 |

### WS /pose/stream

实时姿态识别 WebSocket（触摸屏端持续推流）。

**连接地址：** `ws://<host>:8000/api/v1/pose/stream`

> 说明：前端只连接业务后端（:8000），业务后端内部代理 WebSocket 至 AI 引擎 :8001，统一鉴权与设备景区绑定。

客户端发送：摄像头帧（Base64）的持续流。

服务端推送：

```json
{
  "action": "salute",
  "confidence": 0.92,
  "keypoints": [[120, 80]],
  "triggerContent": {
    "title": "军礼的由来",
    "audioUrl": "/audio/pose/salute.mp3"
  },
  "timestamp": 1730000000000
}
```

连续 3 帧识别到同一动作且 confidence ≥ 0.85 时推送 triggerContent。

## 十六、硬件 TCP 通信协议

> 业务后端通过 `HardwareTcpClient` 与树莓派 `hardware-rpi` 建立 TCP 长连接，换行符 `\n` 分隔 JSON 消息。

### 16.1 通信地址

- 主机：`hardware.tcp.host`（默认 127.0.0.1）
- 端口：`hardware.tcp.port`（默认 9000）

### 16.2 消息格式

下行（后端 → 树莓派）：

```json
{ "cmd": "reboot", "ts": 1730000000000 }
```

上行（树莓派 → 后端）：

```json
{ "event": "pose_detected", "action": "salute", "confidence": 0.92, "ts": 1730000000000 }
```

### 16.3 指令列表

| cmd | 说明 | 参数 |
| --- | --- | --- |
| reboot | 远程重启 | 无 |
| play_audio | 播放音频 | `audioUrl`: 音频路径 |
| stop_audio | 停止播放 | 无 |
| set_volume | 设置音量 | `volume`: 0-100 |
| start_pose | 启动姿态检测 | 无 |
| stop_pose | 停止姿态检测 | 无 |

### 16.4 事件列表

| event | 说明 | 数据 |
| --- | --- | --- |
| pose_detected | 姿态识别结果 | `action`, `confidence` |
| device_status | 设备状态上报 | `cpuTemp`, `memoryUsage`, `diskUsage`, `hailoStatus` |
| audio_finished | 音频播放完成 | `audioUrl` |
| error | 硬件异常 | `message` |
