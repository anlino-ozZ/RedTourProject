# 01 代码统一规范

> 红色文旅智能导览系统 · 全局代码规范（前端 + Python），团队强制遵守。

## 一、前端规范（Vue3 + TS）

### 1.1 通用
- 统一使用 **Vue3 `<script setup lang="ts">`** 组合式 API，禁止 Options API。
- TypeScript 严格模式（`strict: true`），禁止隐式 any；必要时用 `// eslint-disable` 临时豁免并注明原因。
- 所有 Vue/TS 文件统一用根目录 `.eslintrc.js` + `.prettierrc` 格式化，提交前执行 `npm run format`。
- 文件编码统一 UTF-8、无 BOM、行尾 LF。

### 1.2 命名
- 组件文件名：PascalCase（如 `SpotList.vue`）；公共组件加 `Red` 前缀（如 `RedButton.vue`）。
- 变量/函数：camelCase；常量：UPPER_SNAKE_CASE；类型/接口：PascalCase。
- 路由 path 用 kebab-case（如 `/spot-detail`），name 用 PascalCase。

### 1.3 目录与引用
- 业务页面放 `src/views`，复用组件放 `src/components`，接口放 `src/api`，状态放 `src/store`。
- 公共组件、类型、工具统一从 `@red-tour-project/common`（别名 `@common`）引入，禁止重复造轮子。
- 三套前端 `main.ts` 必须引入 `@common/style/index.less` 保证视觉统一。

## 二、后端与脚本规范

### Java 后端（server-business · SpringBoot）
- Java 17 + SpringBoot 3，Maven 工程分层 `controller / service / mapper`，禁止跨层调用（controller 不直接调 mapper）。
- 统一返回 `ApiResponse<T>`，异常走 `@RestControllerAdvice` 全局处理。
- MyBatis mapper：接口放 `mapper` 包，简单 SQL 用注解，复杂 SQL 写 `resources/mapper/*.xml`。
- 用 `mvn clean package` 构建，不依赖 IDEA 内置构建；统一用 Lombok 注解生成 getter/setter。

### Python（ai-engine / hardware-rpi）
- Python 3.10+，统一使用 **Ruff** 格式化与检查（行宽 100，导入排序）。
- 类型注解必填（参数与返回值），使用 `pydantic` 做数据校验。
- 模块独立虚拟环境 `venv`，依赖写入各自 `requirements.txt`，虚拟环境不入库。
- 中文注释简洁不冗余，函数/类需 docstring 说明用途。

## 三、Git 提交规范

- 提交信息格式：`<type>(<模块>): <描述>`，type 取值 `feat / fix / docs / style / refactor / chore / test`。
  - 示例：`feat(admin): 新增景点管理列表页`、`fix(ai): 修正姿态识别阈值`。
- 仅提交本人业务代码与文档，**禁止改动他人模块代码**。
- 单次提交聚焦单一目的，避免混合多模块改动。

## 四、分支规范（详见 README）

- `main`（仅最终合并，禁直接 push）、`dev`（日常集成）。
- 功能分支 `feat/模块-功能-年月日-名字缩写`，修复分支 `bugfix/模块-功能-年月日-名字缩写`，**全英文 + 大驼峰**，禁止中文。
- 模块名首字母大写：`H5` / `Admin` / `Touch` / `Server` / `Ai` / `Rpi` / `Common`。
- 年月日 8 位：`YYYYMMDD`；名字缩写：姓+名拼音首字母大写（如 ZAL/YST/MPH/YYJ/NJY）。
- 示例：`feat/Admin-ScenicManagement-20260809-ZAL`、`bugfix/H5-AudioPlaybackStuck-20260810-NJY`。

## 五、任务管理

团队通过微信群沟通 + 群共享文档管理任务分配与进度，不使用 GitHub Issue。

## 六、文档规范

- 仓库 `docs/` 存开发文档（代码规范 / UI 规范 / 架构硬件 / PRD 需求 / 接口文档）；完整业务 PRD 变更记录、风险表放外部腾讯文档。
- 接口变更须同步更新 `docs/05_全局接口精简文档.md` 与 `public-common/api-types/index.ts`。
