# 03 系统架构 & 硬件清单

> 树莓派5 + Hailo8L 边缘离线 AI 文旅系统架构与硬件清单。

## 一、整体架构

```
┌─────────────── 三端前端（Vue3） ───────────────┐
│  web-h5 游客端   web-admin 管理后台   web-touch 触摸屏 │
└───────────────────────┬─────────────────────────┘
            (HTTPS / Axios，统一 @red-tour/common 类型)
┌───────────────────────▼─────────────────────────┐
│  server-business（SpringBoot :8000）                │
│  业务接口 · MySQL 持久化 · Redis 缓存 · JWT 鉴权  │
└───────────┬───────────────────────────┬─────────┘
            │ 业务问答/识别请求          │ 设备状态/事件
┌───────────▼───────────────┐ ┌──────────▼──────────────┐
│ ai-engine（FastAPI :8001） │ │ hardware-rpi（树莓派5）  │
│ Ollama · YOLOv8-pose       │ │ 串口 · 音频 · GPIO       │
│ LLM Wiki · 机架工程 Harness │ │ 摄像头采集 → AI 引擎      │
└───────────┬───────────────┘ └──────────▲──────────────┘
            │ Hailo8L 加速推理           │ 音视频/LED 反馈
            └────────────────────────────┘
```

- **数据流**：前端 → 业务后端（鉴权/CRUD/缓存）→ AI 引擎（问答/姿态）→ 硬件（采集/反馈）。
- **离线优先**：AI 引擎与硬件脚本运行于树莓派本地，断网仍可用；业务后端与数据库亦部署在边缘节点。

## 二、AI 技术架构要点

| 模块 | 技术要点 |
| --- | --- |
| LLM Wiki | 将党史/地方志/老兵家书等原始素材**编译**为结构化互联 Markdown 百科，摄入时合成、建立 `[[wiki-links]]`，知识复利，规避 RAG 切片式幻觉与“知识蒸发” |
| 机架工程 Harness | 六组件（执行环境/工具注册表/上下文管理器/状态存储/生命周期钩子/评估接口）；策略含 LocalContextMiddleware 注入环境地图实现零回合定向、推理三明治（关键决策高推理/润色轻量）、验证门 + todo.md 协议核对 Wiki 引用冲突则回滚 |
| YOLOv8-pose | Hailo8L 13~26 TOPS 加速，30+ FPS；交互链路识别敬礼/推磨/挥手触发讲解，感知链路识别游客驻足展品主动介绍 |
| Ollama | 本地大模型推理，问答响应 ≤ 3 秒 |

## 三、硬件清单

| 设备 | 型号 / 规格 | 用途 |
| --- | --- | --- |
| 主控 | 树莓派5 8GB（Broadcom BCM2712，PCIe 2.0/3.0） | 边缘计算中枢，运行业务后端/AI 引擎/硬件脚本 |
| AI 加速 | Hailo-8L AI HAT+（13~26 TOPS） | YOLOv8-pose 实时姿态/物体识别加速 |
| 存储 | NVMe SSD（PCIe Gen3） | 高频读取、模型与 Wiki 存储 |
| 散热 | 官方主动冷却（风扇） | 密闭展示柜/户外稳定运行 |
| 视觉 | USB 摄像头（1080p） | 姿态识别/文物感知 |
| 音频 | 外置音箱/喇叭 | TTS 讲解、背景音 |
| 显示 | 触摸屏（触摸屏端专用） | 大屏互动导览 |
| 串口/GPIO | 串口模块 + LED/按钮 | 外设控制、状态指示 |
| 电源 | 官方 27W USB-C 电源 | 稳定供电 |

## 五、部署拓扑

- 边缘节点（树莓派5）：server-business:8000 + ai-engine:8001 + hardware-rpi 脚本 + MySQL/Redis。
- 三端前端构建产物（`dist/`）由树莓派 Nginx 静态托管，离线可访问。
- 开发期：前端在开发机运行（dev server），通过 `.env.development` 指向树莓派后端地址。
