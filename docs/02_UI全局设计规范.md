# 02 UI 全局设计规范

> 三套前端（游客 H5 / PC 管理后台 / 触摸屏大屏）统一视觉基调，杜绝 UI 不一致。

## 一、色彩体系（主色革命红 #C41E3A）

| 用途 | 变量 | 色值 |
| --- | --- | --- |
| 主色（按钮/导航/强调） | `@color-primary` | `#C41E3A` |
| 主色悬停 | `@color-primary-hover` | `#D92647` |
| 主色按下 | `@color-primary-active` | `#A31830` |
| 主色浅底（hover 背景） | `@color-primary-light` | `#FDECEF` |
| 辅助金（勋章/强调） | `@color-accent` | `#D4AF37` |
| 成功 / 警告 / 危险 | success/warning/danger | `#52C41A` / `#FAAD14` / `#FF4D4F` |
| 正文 / 次要 / 边框 | text/border | `#1F1F1F` / `#8C8C8C` / `#E0E0E0` |
| 页面背景 / 卡片背景 | bg-page/bg-card | `#F5F5F7` / `#FFFFFF` |

> 所有色值统一定义在 `public-common/style/variables.less`，三端引用，禁止硬编码颜色。

## 二、字体

- 全局字体：**思源黑体**（Source Han Sans SC / Noto Sans SC），降级 PingFang SC / Microsoft YaHei。
- 基础字号 14px；标题 16px；触摸屏端放大至 3rem+ 以适应远距离触控。

## 三、间距 / 圆角 / 阴影

- 间距阶：`xs 4 / sm 8 / md 16 / lg 24 / xl 32`（px）。
- 圆角：`sm 4 / base 8 / lg 12`。
- 卡片阴影：`0 2px 12px rgba(0,0,0,0.08)`；hover 阴影：`0 6px 20px rgba(196,30,58,0.15)`。

## 四、公共组件标准（public-common）

三端**强制**使用以下公共组件，禁止各自重写：

| 组件 | 用途 | 关键 Props |
| --- | --- | --- |
| `RedButton` | 红色按钮 | `type: primary/ghost/text`、`size: small/medium/large`、`disabled`、`loading` |
| `RedDialog` | 公共弹窗 | `v-model:visible`、`title`、`width`，具名插槽 `footer` |
| `RedCard` | 卡片容器 | `title`、`shadow: always/hover/never` |
| `RedNav` | 顶部导航 | `items: NavItem[]`、`title`，自动路由高亮 |

使用示例：

```vue
<script setup lang="ts">
import { RedCard, RedButton } from '@red-tour/common'
</script>
<template>
  <RedCard title="景点推荐">
    <RedButton type="primary" @click="onStart">开始导览</RedButton>
  </RedCard>
</template>
```

## 五、三端差异化

| 端 | 布局 | 交互要点 |
| --- | --- | --- |
| 游客 H5 | 单列移动端，底部 Tab | viewport 禁缩放，适配刘海屏，支持语音播报 |
| PC 管理后台 | Element Plus `el-container`，左侧 `el-menu` + 顶部 `RedNav` | 表格/表单为主，权限按角色显隐菜单 |
| 触摸屏大屏 | 全屏、无登录、超大按钮 | 字号 ≥ 3rem，按钮 `size=large`，支持语音提问与姿态互动入口 |

## 六、Element Plus 主题对齐

- 后续可通过 Element Plus 主题变量覆盖，将 `--el-color-primary` 对齐 `#C41E3A`，保持与 public-common 主色一致。
- 触摸屏端优先使用 public-common 超大按钮，Element Plus 仅用于表格/表单等复杂控件。
